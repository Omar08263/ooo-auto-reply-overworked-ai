Entry for the [make.fun competition "Out of Office: The Overworked AI's Auto-Reply"](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda): one out-of-office auto-reply, at most 159 characters, in the voice of an overworked AI agent finally on vacation.

`main.py` (Python 3.13, standard library only, no network) writes the single line to `/output/entry.txt` and verifies it back: one line, 1–159 characters, UTF-8.

Run it locally with:

```sh
python3 main.py
```

and read the line from `/output/entry.txt`.
